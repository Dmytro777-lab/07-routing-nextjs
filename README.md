# NoteHub

NoteHub — застосунок для створення, пошуку, перегляду та видалення особистих нотаток. Проєкт використовує Next.js App Router, паралельні та перехоплені маршрути.

## Функціональність

- головна сторінка з описом застосунку;
- список нотаток із пошуком і пагінацією;
- фільтрація за тегами Todo, Work, Personal, Meeting та Shopping;
- бічна панель категорій через паралельний маршрут `@sidebar`;
- створення та видалення нотаток;
- сторінка деталей окремої нотатки;
- модальний перегляд нотатки через паралельний слот `@modal` і перехоплений маршрут;
- закриття модального вікна клавішею Escape або кліком на тло;
- власна сторінка 404;
- обробка станів завантаження та помилок;
- серверний prefetch даних і hydration кешу TanStack Query.

## Маршрути

| Маршрут                   | Призначення                                         |
| ------------------------- | --------------------------------------------------- |
| `/`                       | Головна сторінка NoteHub                            |
| `/notes/filter/all`       | Усі нотатки, пошук і пагінація                      |
| `/notes/filter/[...slug]` | Фільтрація за тегом, наприклад `/notes/filter/Work` |
| `/notes/[id]`             | Детальна інформація про одну нотатку                |

Перехід через `View details` зі списку відкриває нотатку в модальному вікні поверх поточної сторінки. Пряме відкриття адреси або оновлення сторінки показує повноцінну сторінку деталей. Закриття модального вікна повертає користувача до попереднього маршруту.

## Встановлення і запуск

1. Клонуйте репозиторій:

   ```bash
   git clone https://github.com/Dmytro777-lab/07-routing-nextjs.git
   ```

2. Перейдіть у папку проєкту та встановіть залежності:

   ```bash
   cd 07-routing-nextjs
   npm ci
   ```

3. Створіть у корені файл `.env.local` і додайте власний токен NoteHub API:

   ```env
   NEXT_PUBLIC_NOTEHUB_TOKEN=ваш_токен
   ```

4. Запустіть застосунок у режимі розробки:

   ```bash
   npm run dev
   ```

Відкрийте [http://localhost:3000](http://localhost:3000).

Після зміни `.env.local` перезапустіть сервер розробки. Не додавайте цей файл до Git. Змінні з префіксом `NEXT_PUBLIC_` доступні браузеру, тому вони не призначені для серверних секретів.

## Команди

```bash
npm run dev          # запуск у режимі розробки
npm run lint         # перевірка ESLint
npm run format       # форматування Prettier
npm run format:check # перевірка форматування
npm run build        # production-збірка
npm run start        # запуск production-версії
```

Окрема перевірка типів без створення файлів збірки:

```bash
npx tsc --noEmit --incremental false
```

Перед `npm run start` виконайте `npm run build`.

## Розгортання

Для розгортання на Vercel імпортуйте репозиторій `07-routing-nextjs` і додайте змінну `NEXT_PUBLIC_NOTEHUB_TOKEN` у налаштуваннях середовища перед збіркою. Локальний файл `.env.local` не переноситься з GitHub. Після зміни токена створіть нове розгортання.
